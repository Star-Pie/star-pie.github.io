# 本批公开网站改进

本批候选以现有赞助页面为基础，保留主页、深浅主题与双语外观。
网站与支持服务分别运行；当前改动不代表已经上线。

## 已同步到网站源码

- 公开数据已恢复 v1：统一币种、累计金额、稳定编号、昵称、可选头像与主页；按金额降序、同额按编号排列。金额保存在公开 JSON 中，订单、凭证与 Token 仍不公开。
- 使用已确认的爱发电入口，增加微信赞赏码、支付宝扫码选择面板。
- 二维码未配置时明确显示暂未开放；真实图片需由维护者核对后配置。
- 构建只复制当前引用的头像和二维码，后续构建移除已退役图片。
- 二维码图片 URL 带内容版本，替换后需重新生成并发布。
- 改为邮箱申请加入、修改和移除展示；联系邮箱为 erisnebula09@gmail.com，支持者网页填写已停用。
- 增加可直接使用的生成、检查和预览命令，并保留相关回归测试。

## 当前默认资料

正式 sponsors 名单为空，两张二维码来自维护者已启用的公开收款码，contactEmail 为用户指定公开邮箱。
仓库不带本机测试支持者、测试图片或私有核对资料。
当前正式名单保持为空。v1 要求真实的 currency / amountMinor，不以虚构值填补 v2 缺失信息；加入名单前须取得包括排序金额在内的公开授权。
独立控制台若仍导出 v2，需要在该工具中另行适配 v1；本次没有修改独立控制台或自动导入其私有账本。

维护者收到独立管理台的公开资料包后，核对本人授权、收款方和名单增删，再更新对应源文件、
执行生成与构建。公开仓库中的金额、图片和历史都按公开信息处理。

## 继续留在独立支持服务的内容

旧网页提交功能已停用。手动录入、审核、SQLite、爱发电 Token、API 查询、备份及旧 Docker/Webhook 备选文件
不在本批网站同步范围。网站不会自动把扫码或来信视为到账，也不会自动批准公开展示。

当前使用 GitHub Pages + 邮件联系 + 维护者本机控制台，无需独立服务器或域名。真实二维码核对后可通过控制台公开资料包交付。
实际发布、主程序 README 对接与真实订单联调分别执行；本批本地同步不执行这些操作。
